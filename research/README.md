# Research

| Directory | Contents |
|---|---|
| `papers/` | Paper notes: what it claims, whether it applies here, what it would cost |
| `public_solutions/` | Analysis of public KuaiRand / recsys solutions |
| `ideas/` | Raw ideas before they become hypotheses |
| `hypothesis_queue/` | Formed hypotheses awaiting an experiment, priority-ordered |
| `rejected/` | Rejected directions, with reasoning |

Owner: Sarthak.

Every technique becomes a **hypothesis** before it becomes an implementation commitment.
The template is `docs/research/hypotheses/HYPOTHESIS_TEMPLATE.md`.

Rejected ideas stay in the repository. Knowing what was considered and dismissed, and
why, is part of the audit trail the challenge asks for.
